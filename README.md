# Dashboard de producción de Velour Garments

1. En **Settings → Secrets and variables → Actions**, crear:
   - SHOPIFY_STORE_DOMAIN
   - SHOPIFY_CLIENT_ID
   - SHOPIFY_CLIENT_SECRET
2. En **Settings → Pages → Source**, seleccionar **GitHub Actions**.
3. Entrar en **Actions → Actualizar dashboard → Run workflow**.

Se actualiza diariamente a las 06:00, hora de Madrid.
